# Our Little Forever

A mobile-first Midnight Romance birthday website for Baby Cakes, with fourteen interactive sections.

[Open the birthday website](https://kevorwilliams18-a11y.github.io/our-little-forever/)

Edit `content.js` to personalize the content and add your photos and recordings. See [CUSTOMIZE.md](CUSTOMIZE.md) for the complete guide.

The site saves hearts and wishes in the visitor’s browser. Upload previews are temporary. No build step or API keys required.
